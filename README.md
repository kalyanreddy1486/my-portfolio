# Kambala Kalyan Reddy · Portfolio

**Live: [kalyan-reddy.vercel.app](https://kalyan-reddy.vercel.app)**

Personal portfolio of an AI & ML student at Jain (Deemed-to-be University), Bengaluru.

## Highlights

- **You are the light.** The hero portrait is relit in real time with a WebGL shader. A red key light sweeps in on load, then follows your cursor (or finger on phones).
- **Robot agents build the page.** Up to 24 named cursors type, paint and place each section as it scrolls into view, then measure and QA-check finished work. Press `T` for a guided tour, `A` to toggle agents, `P` to pause.
- **Real projects.** HostelOS, Sign-Bridge ASL, MetroNear and a real-time streaming analytics pipeline, each told as problem, build and result with live links.
- **Fast and accessible.** Lighthouse 100 for accessibility, best practices and SEO, with reduced-motion support.

## Stack

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · WebGL · lucide-react · deployed on Vercel

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000/?agents=on
npm run build
npm run lint
```

`?agents=off` shows the finished page without the build animation.
